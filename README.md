# 转基因时光机

《转基因时光机：从餐桌到医院的生命科学探索》是一个面向本科《生命科学导论》课程的交互式网页项目。项目围绕“转基因的前世今生”，通过时间线、知识地图、互动实验室、复习中心和最终挑战，帮助学习者理解转基因食品安全、转基因植物、转基因动物、基因治疗与基因编辑等主题。

## 运行方式

进入项目文件夹后安装依赖：

```bash
npm install
```

启动本地网页：

```bash
npm run dev
```

浏览器打开终端显示的网址，通常是：

```text
http://localhost:5173/
```

## 正式预览

```bash
npm run build
npm run preview
```

## 项目说明

- 技术栈：React + Vite + TypeScript
- 无后端，不调用真实 API
- 学习进度保存在浏览器 localStorage
- 所有课程内容、题目和案例数据集中在 `src/data`
- 项目仅用于课程展示和科普学习，不包含真实实验参数、真实操作流程或真实基因编辑实验指导
